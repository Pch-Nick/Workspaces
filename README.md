# Workspaces

Рабочие пространства для Windows: запомните набор открытых программ с расположением окон и переключайтесь между ними одним кликом. Лишнее сворачивается, нужные программы запускаются и встают на свои места. Управлять можно из окна приложения, из значка в трее или из **Virtual Notch**, острова, который выезжает у верхнего края экрана при наведении мыши.

## Возможности

- Создание, переименование и удаление рабочих пространств.
- Добавление и удаление приложений в пространстве, запуск программ при переключении.
- Сворачивание окон предыдущего пространства и восстановление окон при возвращении.
- Файлы и ссылки, которые открываются вместе с пространством.
- Глобальные горячие клавиши для каждого пространства.
- Virtual Notch: плавное появление и скрытие, не забирает фокус, не мешает полноэкранным окнам.
- Настройки внешнего вида: темы, акцентный цвет, размеры и анимации острова, положение, выбор монитора.
- Значок и цвет каждого пространства, порядок карточек меняется перетаскиванием.
- Русский и английский языки.
- Значок в трее, автозапуск вместе с Windows.
- Надёжное хранение данных: автосохранение, резервные копии, восстановление повреждённых файлов.
- Импорт и экспорт пространств.
- Проверка обновлений через GitHub Releases.

## Установка

1. Скачайте установщик `Workspaces-Free-Setup-<версия>.exe` в разделе [Releases](https://github.com/Pch-Nick/Workspaces/releases).
2. Запустите его и следуйте шагам мастера (права администратора не нужны).

## Как пользоваться

1. Откройте нужные программы и расставьте окна.
2. Нажмите «Запомнить пространство» и введите название.
3. Переключайтесь кликом по карточке, через остров (подведите мышь к верху экрана по центру) или значком в трее.
4. Правый клик по карточке открывает меню: приложения, значок и цвет, горячая клавиша, файлы и ссылки, обновление раскладки, переименование, удаление.

Данные хранятся в `%APPDATA%\Workspaces`: `workspaces.json`, папка `Backups` (резервные копии) и `logs` (журнал ошибок).

## Сборка из исходников

Требуется [.NET SDK 8](https://dotnet.microsoft.com/download) и, для установщика, [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```bat
build-release.bat   :: Release-сборка в publish\ и установщик в dist-installer\
run-tests.bat       :: автотесты (xUnit)
```

Дополнительные заметки для разработчика: [README-DEV.md](README-DEV.md).

## Обновления

Приложение проверяет последний релиз этого репозитория при запуске (отключается в настройках) и по кнопке «Проверить». Чтобы выпустить обновление, создайте релиз с тегом вида `v1.3.1` и приложите файл установщика `.exe`.
